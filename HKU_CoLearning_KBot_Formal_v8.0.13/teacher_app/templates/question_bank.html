How to fill in the templates

Replace the sample questions and details. Keep question IDs consistent between sheets.

  • T/F & MCQ: use the Excel template above. TF answers are TRUE/FALSE; MCQ answers are a single option letter A–E.
  • Matching: fill Questions and Matching. Each detail row is one correct pair; keep left/right IDs unique. This version supports 2–20 one-to-one pairs.
  • Fill Blank: write placeholders such as {{ '{{blank1}}' }} in Questions. In Blanks, add a row for every accepted answer for each blank. Set ignore_case to TRUE or FALSE.
  • Short Answer: provide a reference answer in Questions, then add scoring criteria and points in Rubric. Total points are calculated for you. Uploading a rubric does not enable automatic grading.

Keep the sheet names and headers from the downloaded templates. Original T/F and MCQ files remain supported.
